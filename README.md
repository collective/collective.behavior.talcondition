## Overview

This package provides a Dexterity behavior.

It adds two fields on a content type:

- tal_condition : enter a [TAL expression](https://zope.readthedocs.io/en/latest/zopebook/AppendixC.html) that once evaluated will return 'True' if content should be available. By default, elements 'member', 'context' and 'portal' are available for the expression but the TAL expression context may be extended using the 'extra_expr_ctx' parameter.

- roles_bypassing_talcondition : choose the different roles for which the TAL condition will not be evaluated and always considered 'True'

It's then possible to use the 'evaluate' method to test the TAL condition.


## How to use it

Activate the behavior on your content type.


## Compatibility

Version 2.x supports Plone 6.2 on Python 3.10 to 3.14. It works only with Dexterity content types.

For older Plone versions, and for the Archetypes schema extender, use collective.behavior.talcondition 1.1.3.


## Installation

Add `collective.behavior.talcondition` to the dependencies of your project
(`pyproject.toml`, or `requirements.txt` with the Plone constraints), install
it, restart Plone and activate the add-on in *Site Setup* > *Add-ons*.


## Development

Requires [uv](https://docs.astral.sh/uv/). This installs Plone 6.2.3 in `.venv`
(use `PLONE_VERSION=6.2.2 make install` for another version) and the prek
git hook:

```shell
make install
make start          # Plone on http://localhost:8080 (admin / admin)
```

Create a Classic UI site from the browser, then activate collective.behavior.talcondition.

### Tests

Tests run through tox, as the CI does:

```shell
make test                                   # Plone 6.2.3
uvx --with tox-uv tox -e py314-plone62      # one Plone / Python combination
make test-all                               # lint, every combination, dependencies
```

Without tox:

```shell
.venv/bin/zope-testrunner --test-path=src -s collective.behavior.talcondition
```

### Lint

```shell
make check          # format then lint (pyupgrade, isort, black, zpretty, flake8...)
```

### Translations

```shell
make i18n           # rebuild the collective.behavior.talcondition catalog
```

`.editorconfig`, `.flake8`, `.gitignore`, `.pre-commit-config.yaml`, `tox.ini`,
`.github/` and the tool sections of `pyproject.toml` are generated by
[plone.meta](https://github.com/plone/meta): change `.meta.toml`, then run
`uvx --from plone.meta config-package --no-commit --branch current .`.
